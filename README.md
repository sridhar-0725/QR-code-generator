# QR Code Generator

A simple and efficient **QR Code Generator** built with **Python Flask**. This web application allows users to generate QR codes from text, URLs, or any custom data and instantly download them as PNG images.

---

## 🚀 Features

* Generate QR codes from text, URLs, or custom input
* Download generated QR codes as PNG images
* Clean and user-friendly interface
* Fast QR code generation using Python
* In-memory image processing with `BytesIO`
* Lightweight and easy to deploy
* Compatible with multiple Flask versions

---

## 🛠️ Technologies Used

* Python

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/QR-Code-Generator.git
cd QR-Code-Generator
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Application

```bash
python app.py
```

### 4. Open in Browser

```text
http://127.0.0.1:5000
```

---

## 📖 Usage

1. Enter a text, URL, or any custom data.
2. Click the **Generate QR Code** button.
3. The QR code will be generated instantly.
4. Download the QR code as a PNG image.
